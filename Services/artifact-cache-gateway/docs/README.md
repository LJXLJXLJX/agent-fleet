# docs/

Project documentation.

- `developer-guide.md`: developer guide — module structure, modifications and verification.
- `user-guide.md`: user guide — how clients for each ecosystem connect to the Gateway.
- `operator-guide.md`: operator guide — deployment, source review process, S3 and failure

The behavior the documentation describes is governed by the code and tests; when code changes
alter behavior, update the corresponding documentation accordingly.
